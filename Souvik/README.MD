# DSA in Lab

A collection of Data Structures and Algorithms implemented in C as part of lab exercises.

## Topics Covered

### Stack
- Array-based stack
- Linked list-based stack

### Queue
- Single queue
- Circular queue (with practice variants)

### Linked List
- Singly linked list (insertion & deletion)
- Doubly linked list (insertion & deletion)
- Circular linked list (insertion & deletion)
- Doubly circular linked list (insertion & deletion)

### Expressions
- Infix to Postfix conversion
- Postfix expression evaluation

## Language
C

## How to Run

```bash
gcc <filename>.c -o output && ./output
```
